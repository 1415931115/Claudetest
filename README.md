# 蟠桃园

单人第一人称潜行搜刮游戏。黑暗中提灯进蟠桃园，蹲在树旁搜索，把桃子塞进格子背包，趁仙女没发现你之前撤出去。

## 跑起来

```bash
npm install
npm run dev      # 打开提示的地址，用 Chrome 或 Edge
npm test         # 逻辑测试（Vitest，跑在 Node 里）
npm run build    # 类型检查 + 生产构建
```

## 操作

| 键 | 作用 |
|---|---|
| 点击画面 | 锁定鼠标开始 |
| WASD | 移动 |
| Ctrl | 蹲下（更安静，灯照得更低） |
| Shift | 疾走（会被仙女听见） |
| E | 搜索（按住读条，人会被钉住；松手进度退回 60%） |
| F | 切换灯的亮度（几乎熄灭 / 常亮 / 提亮） |
| F3 | 显示/隐藏性能面板 |
| Esc | 释放鼠标 |

## 现在有什么

一张 40×40 的蟠桃园，八棵桃树，一个撤离点，一只巡逻的仙女。桃子占 2×2 格、值 40；背包 8×6 格。被仙女碰到重开，走进撤离点结算并重开。

## 还没有

仓库、灵石、皮肤、三种仙女里的另外两种、随机点位、存档、正式美术（现在全是几何体占位）。

## 目录

```
src/logic/   纯逻辑，不 import three，能在 Node 里测
src/scene/   渲染、输入、光照、仙女实体
src/ui/      HUD 与性能面板
tests/       Vitest
```

`src/logic/` 不碰 three 也不是纯洁癖：这是唯一能自动验证的部分，和只有人能判断手感的部分必须分开。
